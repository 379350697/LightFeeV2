| Adaptation | Reason | Regression coverage |
|---|---|---|

| No-frozen terminal fallback rediscovery skips instead of synthesizing a candidate. | V1 rediscovery depends on `MarketView` and the full Rust candidate discovery/guard/liquidity/prediction chain, which is not available in the pure lifecycle boundary. | `tests/engine/test_v1_pending_entry_lifecycle_parity.py::test_v1_terminal_taker_fallback_without_frozen_candidate_is_explicit_skip`. |
| Runtime performs adapter normalization, post-only submit/retry, cancel, query, and ForceStandard order execution. | V1 methods combine source decisions and async exchange IO; Python adapters expose different APIs. | Pending lifecycle parity tests cover pure mutations; live harness tests cover candidate-derived ForceStandard sizing, checkpoint progress, and post-only retry wrapper behavior. |
| Full `hedge_pending_entry_delta` deadline and terminal driver remains out of scope. | The cleanup scope fixed source-port quantity, price, FIFO, and inflight/idempotency semantics but did not complete the V1 hedgeability/deadline/terminal driver. | `tests/live_harness/test_passive_maker_zero_fill_incident.py::test_live_hedge_drive_consumes_maker_remainder_fifo`; `tests/test_live_entry_hedge_root_fix.py`. |
| Restored pending entries without remainder slices fall back to legacy maker/hedge fill deltas. | Old snapshots predate V1 remainder slices. Exact V1 vector state cannot be reconstructed without live fill history. | FIFO parity tests cover legacy fallback and explicit slices. |
| Funding horizon hunks are deferred in this matrix. | They belong to the earlier V1 lifecycle-core scope, not pending-entry passive opening source-port. | Existing lifecycle-core tests remain in the broad regression gate. |
